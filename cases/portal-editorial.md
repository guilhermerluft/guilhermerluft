# Portal editorial com frontend React e CMS headless

**Tipo:** portal de notícias e conteúdo  
**Tecnologias:** React, TypeScript, WordPress e API REST

## Necessidade

Criar uma interface editorial com navegação por categorias, publicação frequente de conteúdos e ferramentas práticas para a equipe administrar o portal.

## Abordagem

Desenvolvimento do frontend com React, consumindo informações de um CMS WordPress por API. A separação permite evoluir a experiência visual e os fluxos de gestão sem acoplar tudo ao tema tradicional do WordPress.

## Funcionalidades trabalhadas

- Listagem de publicações, categorias e páginas de conteúdo.
- Destaques editoriais e busca.
- Administração de artigos e imagens.
- Editor visual e controles de acesso para diferentes responsabilidades.

## Competências demonstradas

**Integração entre React e WordPress headless**, com foco em experiência de navegação e fluxo de publicação para o cliente.
