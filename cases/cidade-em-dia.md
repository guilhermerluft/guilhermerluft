# CidadeEmDia — aplicação React e ASP.NET Core

**Tipo:** aplicação web full stack  
**Tecnologias:** React, TypeScript, ASP.NET Core 10, Entity Framework Core, PostgreSQL/PostGIS, Docker e Nginx  

## Visão geral

Projeto de aplicação web construída do zero, com frontend separado da API, organização de camadas e infraestrutura documentada.

## Abordagem técnica

- Interface construída com React e TypeScript.
- API em ASP.NET Core com separação entre Application, Domain e Infrastructure.
- Integração com PostgreSQL e extensão geoespacial PostGIS.
- Estrutura de testes automatizados, documentação operacional e Docker Compose.

## Competências demonstradas

**Desenvolvimento full stack do frontend à infraestrutura**, utilizando arquitetura organizada e tecnologias adequadas à evolução de uma aplicação web.

## Status

O projeto demonstra a base técnica. Não são afirmadas funcionalidades de negócio concluídas, implantação em produção ou resultados comerciais não comprovados.
