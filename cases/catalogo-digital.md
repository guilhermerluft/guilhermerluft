# Catálogo digital personalizado

**Tipo:** site comercial e catálogo de produtos  
**Tecnologias:** WordPress, PHP, WooCommerce, JavaScript e CSS

## Necessidade

Uma operação comercial precisava apresentar produtos de forma organizada e encaminhar o interesse dos visitantes para um atendimento direto, sem exigir um fluxo de checkout convencional.

## Abordagem

Desenvolvimento de uma experiência de catálogo baseada em WordPress, com páginas específicas para produtos e ferramentas de gestão de informações. A organização do conteúdo e a navegação foram pensadas para a rotina de manutenção do site.

## Funcionalidades trabalhadas

- Navegação por categorias e páginas individuais de produto.
- Galerias de mídia e chamadas para atendimento.
- Gestão administrativa de produtos, menus e conteúdo.
- Recursos de responsividade, organização editorial e SEO.

## Competências demonstradas

**Customização de WordPress para processos comerciais**, integrando interface pública e gestão de conteúdo sem depender apenas dos modelos padrão de um construtor visual.

> Este case é anônimo. Não reproduz código privado, informações internas ou resultados comerciais não verificados.
